Правила:
- не се измислуваат автор, наслов, година, техника, димензии или сопственик;
- оригинал/master се чува одвоено кога е голем или чувствителен;
- во GitHub се внесува само rights-cleared web derivative;
- секој објект добива архивски ID и provenance/rights metadata;
- дупликатите се контролираат со SHA-256.
