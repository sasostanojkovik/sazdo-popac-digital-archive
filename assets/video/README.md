## Preservation policy

Original archive masters remain outside GitHub unless explicitly approved for repository storage.

Source-derived preservation/access copies acquired from public platforms — including current working copies catalogued for `MPS-0007`, `MPS-0008`, `MPS-0009`, `MPS-0010` and `MPS-0012` — are recorded in `data/media.json` with provenance, checksum and technical metadata, but are not automatically stored as repository binaries.

A local or source-derived copy does not by itself imply public-rights clearance. Public distribution, licensing, monetisation and territorial availability are tracked separately from preservation status.

Official public YouTube playback, where available, is treated as the canonical public delivery layer while the archive retains provenance for the original source record.
